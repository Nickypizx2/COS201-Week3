
# COS 201 - Week 3 Assignment

**Course:** Computer Programming I  
**Programme:** Computer Science

## Programs

1. **SimpleCalculator.java** - Performs addition, subtraction, multiplication, and division.
2. **AverageCalculator.java** - Calculates the average of numbers entered by the user.
3. **ItemCost.java** - Calculates the total cost using the item price and quantity.

## How to Compile and Run

Open the terminal in the folder containing the files.

### SimpleCalculator
    javac SimpleCalculator.java
    java SimpleCalculator

### AverageCalculator
    javac AverageCalculator.java
    java AverageCalculator

### ItemCost
    javac ItemCost.java
    java ItemCost
